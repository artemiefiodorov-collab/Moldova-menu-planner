# 🇲🇩 ПланПитания.MD — Умное планирование меню и покупок в Молдове

Самостоятельное веб-приложение (Mobile-First SPA + автоматический сборщик цен) для составления недельного меню на 7 дней в рамках заданного бюджета в молдавских леях (**MDL**), расчёта реальной продуктовой корзины с учётом заводской фасовки товаров и честного сравнения стоимости между супермаркетами Молдовы.

---

## ✨ Ключевые возможности

1. **Актуальные цены супермаркетов Молдовы (без выдуманных цен)**
   * База товаров формируется и обновляется из реальных открытых онлайн-каталогов:
     * **[Metro Moldova (Zakaz.md)](https://metro.zakaz.md/ru/)** — 100% покрытие базовой продуктовой корзины, серверный HTML (SSR), прямые ссылки на карточки товаров с весом упаковки, штрихкодами EAN и ценами в MDL.
     * **[Kaufland Moldova](https://www.kaufland.md/ru/predlozheniya/obzor-aktsiy.html)** — открытый еженедельный каталог акций и предложений Kaufland Card XTRA с пересчётом цены за 1 кг / 1 л.
     * **[Redu.md](https://redu.md/)** — независимый агрегатор скидок и истории цен за 30 дней по сетям **[Linella](https://redu.md/ru/preturi/linella)**, **[Local](https://redu.md/preturi/local)**, **[Bonus](https://redu.md/ru/preturi/bonus)**, **[Rogob](https://redu.md/ru/preturi/rogob)**, **[Fidesco](https://redu.md/ru/preturi/fidesco)** и **[Nr.1](https://redu.md/ru/preturi/nr1)**.
   * **Честная индикация недоступных источников**: прямые запросы к `linella.md` блокируются межсетевым экраном (WAF), а сервис [Croco.md](https://play.google.com/store/apps/details?id=md.croco.app&hl=ru) работает исключительно как закрытое мобильное приложение без веб-каталога. Если товар отсутствует в открытом промо-каталоге конкретного магазина, приложение явно указывает статус `Нет в открытом каталоге`, не подставляя вымышленные цены.

2. **Генерация меню на 7 дней под бюджет семьи**
   * Настройка бюджета на неделю (например, `1 000 MDL` или `1 500 MDL`), количества человек (`1–8`), приёмов пищи (`Завтрак`, `Обед`, `Ужин`, `Перекус`), типа питания (`Традиционное молдавское`, `Экономное`, `Белковое`, `Без свинины`, `Вегетарианское`), сложности приготовления и исключённых продуктов.
   * Подбор 28 проверенных рецептов из открытых кулинарных источников ([1000.menu](https://1000.menu/), [IamCook.ru](https://www.iamcook.ru/), [RussianFood.com](https://www.russianfood.com/)) с точными граммовками, пошаговой инструкцией, временем готовки, КБЖУ и прямыми ссылками на оригинал рецепта.
   * Замена любого блюда в 1 клик и кнопка **«Оптимизировать под бюджет»**, которая автоматически заменяет дорогие позиции на более доступные блюда с общими ингредиентами, если чек превышает лимит.

3. **Умный расчёт бюджета: «Сумма в чеке (упаковками)» vs «Себестоимость блюд (нетто)»**
   * Приложение суммирует одноимённые ингредиенты по всем дням недели (например, сметану из сырников, запеканки и мамалыги) и переводит их в реальные магазинные упаковки.
   * Если для всех рецептов недели требуется `200 г` сметаны, а в магазине продаётся стакан [President 20% 350 г за 22.95 MDL](https://www.kaufland.md/ru/predlozheniya/obzor-aktsiy.html):
     * **В чеке корзины** учитывается полная стоимость упаковки (`22.95 MDL за 350 г`).
     * **В себестоимости блюда** учитывается только фактически использованный объём (`13.11 MDL за 200 г`).
     * **В остатке дома** отображается неизрасходованный запас (`150 г на сумму 9.84 MDL`), который остаётся в холодильнике на следующую неделю.

4. **Единый список покупок и сравнение магазинов**
   * Разделение покупок по 8 отделам супермаркета: *Овощи и фрукты*, *Мясо и птица*, *Рыба*, *Молочные продукты*, *Бакалея*, *Крупы и макароны*, *Хлеб и выпечка*, *Прочее*.
   * Отметка уже купленных товаров и переключатель **«Уже есть дома»** для базовой бакалеи (соль, сахар, подсолнечное масло, мука, уксус), мгновенно уменьшающий сумму к оплате на кассе.
   * Экспорт списка покупок и недельного меню в **PDF** или текстовое сообщение для Telegram / WhatsApp.

## 📁 Структура репозитория

```text
moldova-meal-planner/
├── index.html                        # Самостоятельное SPA-приложение (Mobile-First UI)
├── data/
│   ├── prices.json                   # Кэш актуальных цен, упаковок и URL товаров в MDL
│   └── recipes.json                  # База проверенных рецептов с граммовками и КБЖУ
├── backend/
│   ├── scraper.py                    # Парсер цен Metro.zakaz.md, Kaufland.md и Redu.md
│   └── server.py                     # Опциональный HTTP/API-сервер с TTL-кэшированием
├── .github/
│   └── workflows/
│       └── update-prices.yml         # Автообновление цен по расписанию (GitHub Actions)
├── requirements.txt                  # Зависимости Python для парсера (BeautifulSoup4, lxml)
└── README.md                         # Инструкция по запуску, архитектуре и развёртыванию
```

## 🚀 Инструкция по запуску и бесплатному развёртыванию

### Вариант 1: Полностью бесплатный хостинг на GitHub Pages + GitHub Actions (Рекомендуется)

Архитектура проекта спроектирована по принципу **Git-scraped Static Cache**: вам не нужно оплачивать внешний VPS-сервер для регулярного парсинга цен. Воркфлоу GitHub Actions каждые 12 часов запускает Python-парсер на виртуальной машине GitHub, собирает свежие цены с сайтов Молдовы и сохраняет обновлённый `data/prices.json` в репозиторий, откуда его мгновенно читает клиентское приложение.

1. Создайте новый публичный репозиторий на [GitHub](https://github.com/new) и загрузите в него содержимое папки проекта.
2. Перейдите в **Settings → Actions → General → Workflow permissions** и выберите **Read and write permissions**, чтобы робот GitHub Actions мог сохранять обновлённый кэш `data/prices.json`.
3. Перейдите в **Settings → Pages** и в разделе **Build and deployment** выберите источник `Deploy from a branch` → ветка `main` (папка `/ (root)`).
4. Откройте вкладку **Actions**, выберите воркфлоу **Auto-Update Moldova Grocery Prices** и нажмите **Run workflow** для первого принудительного обновления цен.
5. Через 1 минуту ваше приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/` со смартфона и компьютера. Никакие API-ключи в репозитории не требуются и не хранятся.

### Вариант 2: Локальный запуск и обновление цен вручную

```bash
# 1. Установите зависимости Python (только для запуска парсера)
pip install -r requirements.txt

# 2. Обновите кэш цен из магазинов Молдовы (с флагом --force для обхода 6-часового кэша)
python backend/scraper.py --force

# 3. Запустите локальный сервер (раздаёт index.html и эндпоинты /api/prices, /api/refresh)
python backend/server.py
```
После запуска откройте `http://localhost:8080` в браузере или на смартфоне в локальной сети.

### Вариант 3: Развёртывание Backend-сервера на Render.com / Railway / Fly.io

Если вам нужен живой REST API (`/api/prices`, `/api/refresh`) с динамическим обновлением по кнопке:
1. Подключите ваш GitHub-репозиторий к бесплатному веб-сервису [Render.com](https://render.com/).
2. Укажите **Build Command**: `pip install -r requirements.txt`
3. Укажите **Start Command**: `python backend/server.py`
4. Сервер автоматически подхватит переменную окружения `PORT` и будет отдавать как само веб-приложение, так и JSON API с кэшированием на 6 часов.
