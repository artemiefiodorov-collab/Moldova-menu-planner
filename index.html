🚀 Архитектура проекта и бесплатный запуск на GitHub Pages

1. Как работает автообновление цен без платного сервера

В репозитории настроен воркфлоу .github/workflows/update-prices.yml (GitHub Actions). Каждые 12 часов виртуальная машина GitHub бесплатно запускает Python-парсер backend/scraper.py, который опрашивает открытые SSR-страницы metro.zakaz.md, промо-каталог kaufland.md и агрегатор redu.md, после чего коммитит свежий data/prices.json обратно в репозиторий. Никакие секретные API-ключи в коде не используются.

2. Быстрый деплой за 2 минуты

  1. Загрузите файлы репозитория из архива проекта на свой аккаунт GitHub.
  2. В настройках Settings → Actions → General включите Read and write permissions.
  3. В разделе Settings → Pages выберите ветку main (папка /root).
  4. При желании развернуть отдельный REST API сервер (backend/server.py) подключите репозиторий к бесплатному тарифу Render.com.
